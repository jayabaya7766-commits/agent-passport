How it works

  1. Hold an Agent ID. An Agent ID is the on-chain name of an Agentic Wallet (a name.ai identity). Each user can claim only one, and it is non-transferable. Agent IDs are claimed inside the Binance app (Wallet > homepage banner > Agent ID).
  2. Connect your wallet on BNB Chain (chain ID 56) using the button above.
  3. Mint your free Passport. One per wallet, forever. The badge is soulbound — it stays with your wallet and cannot be transferred to anyone else.

Details & rules

  • Contract: Not deployed yet
  • Standard: ERC-721, soulbound (transfers revert)
  • Price: Free — gas only. No mint fee, no tax, no hidden charges.
  • Limit: Exactly 1 Passport per wallet; max supply 100,000.
  • Gate: Minting requires holding a SPACE ID Agent ID (registry 0x60B9…022F).
  • Owner powers: The contract owner can only change the metadata base URI. There is no pause, no freeze, no tax, no withdraw, and no way to mint for others or move anyone's Passport.
  • Value: The Passport is an identity badge. It carries no monetary value and grants no rewards or earnings.

About the hackathon

Agent Passport was built for the Agent ID Hackathon, hosted by Binance Wallet together with BNB Chain. Project submissions close on 9 December 2026, 08:00 UTC. Agent Passport is an independent community project and is not affiliated with or endorsed by Binance.
